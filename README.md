# تطبيق حل Load Flow — Newton-Raphson

تطبيق أندرويد أصلي (Kotlin) يحل مسائل تدفق الأحمال بطريقة نيوتن-رافسون،
منقول من نفس منطق كود الماتلاب المرفق سابقاً (NR_LoadFlow.m) — بدون أي
حاجة لتشغيل ماتلاب على الهاتف.

## خطوات التشغيل

1. افتح **Android Studio** (يفضل إصدار Hedgehog أو أحدث).
2. اختر **Open** وحدد مجلد `LoadFlowApp` بالكامل.
3. انتظر حتى يكمل Android Studio مزامنة Gradle (Sync) — يحتاج اتصال
   إنترنت لتحميل مكتبات AndroidX وMaterial أول مرة، وسيقوم تلقائياً
   بإنشاء ملف `gradle-wrapper.jar` الناقص.
4. وصل هاتف أندرويد حقيقي عبر USB (وفعّل خيارات المطور + USB Debugging)،
   أو شغّل محاكي (Emulator) من داخل Android Studio.
5. اضغط **Run ▶** لتثبيت التطبيق وتشغيله.

## طريقة الاستخدام داخل التطبيق

1. **الشاشة الأولى:** أدخل عدد البصات (Buses) في نظامك.
2. **الشاشة الثانية:** لكل بص، اختر نوعه (Slack / PV / PQ) وأدخل:
   - P المحددة (لكل الأنواع ما عدا Slack)
   - Q المحددة (فقط لبصات PQ)
   - |V| (محدد لـ Slack و PV، أو قيمة ابتدائية لـ PQ — عادة 1.0)
   - **لازم يكون هناك بص Slack واحد بالضبط.**
3. **الشاشة الثالثة:** أدخل مصفوفة Ybus كاملة (n×n) — لكل خلية تدخل
   الجزء الحقيقي (G) والجزء التخيلي (B) بالـ per-unit.
4. اضغط **"حل (Newton-Raphson)"** وستنتقل تلقائياً لشاشة النتائج
   (الفولت |V|، الزاوية δ، والقدرة الفعالة/غير الفعالة النهائية لكل بص).

## بنية الكود (الملفات المهمة للتعديل)

- `LoadFlowSolver.kt` — الخوارزمية الرياضية بالكامل (Newton-Raphson +
  الجاكوبيان + حل النظام الخطي بطريقة الحذف الغاوسي). هذا هو المكافئ
  المباشر لكود الماتلاب.
- `Complex.kt` — تمثيل الأعداد المركبة المستخدمة في Ybus.
- `AppData.kt` — تخزين بيانات النظام مشتركة بين الشاشات.
- `MainActivity.kt` / `BusInputActivity.kt` / `YbusInputActivity.kt` /
  `ResultsActivity.kt` — الشاشات الأربع.

## بناء APK بدون تثبيت أي شيء (GitHub Actions)

المشروع يحتوي على ملف `.github/workflows/build.yml` جاهز. الخطوات:

1. أنشئ حساب مجاني على github.com إن لم يكن عندك.
2. أنشئ **New repository** (يفضّل خاص Private).
3. ارفع محتويات مجلد `LoadFlowApp` بالكامل (كل الملفات، بما فيها مجلد
   `.github`) — إما عبر السحب والإفلات في واجهة GitHub، أو عبر git.
4. بعد الرفع، افتح تبويب **Actions** أعلى الصفحة — سيبدأ البناء تلقائياً
   (يأخذ 2-5 دقائق).
5. عند اكتماله بنجاح (علامة ✔ خضراء)، افتح الـ workflow run، وفي أسفل
   الصفحة تجد **Artifacts** → حمّل `app-debug-apk` — هذا ملف APK جاهز
   لتثبيته مباشرة على أي هاتف أندرويد (فعّل "تثبيت من مصادر غير معروفة"
   في إعدادات الهاتف عند التثبيت).

هذا الخيار **مجاني بالكامل** ولا يحتاج تثبيت Android Studio أو أي شيء
على جهازك — كل البناء يحدث على سيرفرات GitHub.

## ملاحظات مهمة

- الحد الأقصى الحالي لعدد البصات هو 30 (يمكن تعديله من `MainActivity.kt`).
- التسامح (tolerance) الافتراضي `1e-6` وأقصى عدد تكرارات `50` — يمكن
  تعديلهما من ثوابت `TOL` و`MAX_ITER` في `LoadFlowSolver.kt`.
- لم يتم اختبار الكود فعلياً بالتصريف (compile) داخل هذه البيئة لعدم
  توفر Android SDK هنا — راجع أي أخطاء بسيطة قد تظهر عند أول Build في
  Android Studio (عادة أخطاء استيراد import بسيطة يسهل حلها).
